HOW TO PLAY

一点随机，一点默契。

  1. 轮流掷 1～3 点骰子，走到落点后处理本格。
  2. 普通格抽一张任务；二选一由自己选；对方决定格由另一人选。
  3. 首次停在留印格，自动留下标记。以后有人落到这里，由标记者从两张候选中选一张。
  4. 每人一局可以多走一格。阶段站必须停下，不能用额外步数越过。
  5. 阶段站共同决定是否解锁下一阶段。任意一人到终点，双方一起收尾。
  6. 随时免费换卡、跳过或暂停。游戏里的选择不代替当下的同意。

任务库支持本机编辑和 HTML 导入导出。部署在 GitHub Pages 的文件通常公开可访问；私人内容建议只在设备上导入。
